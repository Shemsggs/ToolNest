# Frontend Development

Use Next.js App Router, TypeScript strict mode, Tailwind and reusable semantic components. Build light-first white-and-blue interfaces. Validate input limits before resource-heavy browser processing, provide clear progress/errors, and release object URLs. Ensure accessible labels, keyboard interactions, responsive layouts, loading and empty states. Never send files to the server from a browser-only tool. Use signed-in layouts to protect tool access.
